# v3 — the Compounding Organisation

One founder plus an AI workforce that conceives, builds, runs, grows and learns across startups, agencies, businesses,
research and any project he can imagine. The practice is **vibe startuping**. This folder is the full-depth design,
written 2026-09-30 by a five-round process with Claude and Codex as equal thinkers.

**Binding input:** [00-FOUNDER-DIRECTION.md](00-FOUNDER-DIRECTION.md). **Single source of truth for names and decisions:**
[00-CANON.md](00-CANON.md). **Explorer (diagrams, wireframes, search):** https://claude.ai/artifact/Lw6qgjWGAAz6YgV7t1JAoD (private; rebuild per [site/README.md](site/README.md)).
