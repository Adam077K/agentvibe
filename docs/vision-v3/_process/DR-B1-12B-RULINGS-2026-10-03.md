# DR-B1-12B-RULINGS: B1-12b open questions ruled (2026-10-03)

**Source.** The coordinator relayed these rulings to the B1-12b test builder on 2026-10-03. Q1 and Q7 are the
founder's, by AskUserQuestion. Q2–Q6 are orchestrator calls, made fail-safe and consistent with founder rulings A–C

## Founder rulings

- **Q1. Venture source.** The venture is taken from the job's lease, never from the request. One gateway serves one
  venture for now. A request naming a different venture is refused.
  - A lease whose job belongs to another venture is refused with `ErrWrongVenture`.
  - A socket line carrying a `venture` key is refused by the socket (`invalid_field`) before it reaches the gateway.
- **Q7. Effector limits, tight.** Anything else is refused until the limits are widened:
  - email goes only to the founder recipient, matched exactly;
  - a git PR goes only to an allow-listed repo;
  - a deploy is preview only, never production, and the digest must be pinned.

## Orchestrator calls

- **Q2.** An effect with no lease is refused (`ErrNoLease`).
- **Q3.** The target is a string id. Any other JSON type is refused (`ErrInvalidTarget`).
- **Q4.** Lease tokens map a resource to a decimal-string token, for example `{"job://J7":"3"}`.
- **Q5.** There is no separate request id. The business key (venture ‖ verb ‖ target ‖ business_ref) deduplicates.
- **Q6. Changed from the builder's recommendation.** A lease lost mid-dispatch is **not** a definite failure, because
  the effect may have landed.
  - The attempt is Uncertain. It is reconciled by Lookup after the visibility lag (ruling A).
  - It then follows rulings B and C: Human at 15 minutes, and one retry only if the lookup confirms Absent.
  - The new lease holder must not send until that reconcile says Absent.
  - The builder had recommended a definite failure for a lease found stale before the provider call. That
    recommendation is withdrawn.
  - A test pins the case where the old holder's effect landed and the new holder's dispatch is refused, so the effect
    happens exactly once. It covers three endings: the worker dies, the call times out, and the call answers ok.

## Not ruled here

- Widening any Q7 limit.
