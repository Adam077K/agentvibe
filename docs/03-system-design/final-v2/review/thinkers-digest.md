## 2 · What the practitioner measured, and what it falsifies as written

Lane A took every claim it could to this Mac. Each line is a mechanism that does not work as the plan names it.

- **A1** `pmset -g custom` → `sleep 1` on AC and battery, 391 maintenance sleeps in seven days, lid closed daily, on battery at 71%. O15's refusal fires every night; the night mode has no runtime here. R5 was read as *no tail for a cloud lane*; a practitioner reads it as *never awake unattended*.
- **A2** 48 teams, 224 members, 219 `backendType: in-process`, no real pane id anywhere. Page 2's tap can attach only to `-p` children `bin/run` mints in tmux; teammates have no pane. `--tmux` wants iTerm2; the founder runs Ghostty.
- **A3** The founder works in auto mode with the dangerous-mode prompt skipped; the managed file as specified removes that mode machine-wide. The plan prices it at "four lines of JSON."
- **A4** 3,116 transcripts, 3.1 GB, growing 56 a day, under `~/.claude/projects` — outside `keel/`, inside the mining pass, holding every stranger's body verbatim. v69's erasure greps the wrong tree. `--no-session-persistence` exists and is unmentioned.
- **A5** Outbound loopback is denied for sandboxed Bash (`connect: operation not permitted`, measured). A `bin/egress` proxy on 127.0.0.1 is unreachable by the process class it governs; the shape must be a stdio MCP server plus the sandbox network block.
- **A6** Five `ceo-*` worktrees, three terminals, one console login: the founder runs a bullpen, the plan has one Operator, one `founder.last`, one cord, one sterility predicate.
- **A8** `--fallback-model a,b` is shipped and reroutes silently — the thing v78 forbids — and the plan mentions it zero times.
- **A9** `gemini --version` under the live sandbox → EPERM on `~/.gemini/settings.json`; the second family cannot start from any Claude-hosted shell.
- **A10** `--autocompact` is on by default; a long `-p` run is compacted by the runtime, which is the ACE collapse v24 forbids, and costs a 2x cache write on the next turn.
- **A13** The skill metadata tax measured: ~53 tokens per skill, ~7k for 134, ~110k for 2,111.

## 4 · Decisions the round raises that are not on the open list

The orchestrator's recommendation is first in each row. These are for the founder; nothing below is applied.

1. **Who the first stranger is.** Name a customer-facing venture in wave one beside the harness, with a contact-rung-2 target as the exit of `OVERNIGHT`. *Recommended.* (A, B, C)
2. **Buy the always-on box before the first night, not after.** The founder's Mac stays the Floor and the client; the Watch, Sender, log and night move to the box on day one. *Recommended.* (A1, C13)
3. **A commodity line in the doctrine.** `vendor_wins_if:` beside every §L row; build a mechanism only where no vendor surface exists or is announced, or where it is one of the kernel four (direction, record, truth, taste); reorder §19 by it. *Recommended.* (C3, B vision, A vision)
4. **Budget the founder's attention.** A founder-hours ceiling per week on the harness charter, read by the Desk like a token ceiling; a which budget per window; build one option and a written second unless a ten-word summary cannot separate them; the briefing's first line is decisions taken, deferred, defaulted. *Recommended.* (C4, B3, C20)
5. **Run R12 on the founder's own transcripts now, per domain, at zero build cost**, and again on the second venture's real thirty. Define "inventing an anchor" operationally. *Recommended.* (B4, C2)
6. **Two classes of founder row**: originated (the founder's words) and ratified (picked from an agent's list); ratified rows reopenable by any engine with a reason and a falsifier; every future option set carries a genuinely argued second option; a control arm on whiches where the recommendation is hidden. *Recommended.* (B5, B16)
7. **The capacity model as economics.** Compute the shadow API cost of unattended work against the seat price as a briefing line; decouple a checker-family key (Gemini or OpenAI, a few dollars, scoped to checking) from row 1; decide seat-for-the-Floor, metered-for-the-night from R7 and the first overnight. *Recommended.* (B7, C6, C7)
8. **Invert the plan into data before build.** `roster.yml`, `routing.yml`, the four schemas, `prices.yml`, `facts.yml`, `rules.yml` with `mechanism: · path: · state:`; prose rendered from them; a short constitution as the Operator's pre-flight read; superseded paragraphs to an archive. *Recommended.* (B6, C18)
9. **Model the founder's real shape**: N Operators (a row each in `sessions.jsonl`, the which queue takes a claim before answering) or one enforced by lease — a founder behaviour change stated as such. *Recommended: model N.* (A6, A21)
10. **Bounded-day first, night second.** Build Floor, Desk, launcher, Sender, reconciliation and one venture; run row 12's comparison as the first measurement; put the night machinery behind its result. *Recommended.* (C9, A1)

## 7 · The vision, in one line from each chair

Findings are not verified by a second reader; the practitioner's measurements are reproducible by the commands it quotes.
