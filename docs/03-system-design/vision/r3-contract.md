# Synthesis contract — the vision round

**Input:** the three visions (`2026-09-02-flywheel.md`, `2026-09-02-founder.md`, `2026-09-02-machine.md`), the
CEO's sealed position (`2026-09-02-ceo-position.md`, written before any vision returned), the brief, and — only
for §3 below — `docs/03-system-design/STARTUP-OS.md` Part II (the year-one frame).

**Output:** `docs/03-system-design/vision/2026-09-02-THE-PICTURE.md`, ≤ 700 lines:

```
1. THE PICTURE          one merged vision, written as a visit. Where the three agree, take it. Where they differ,
                        DECIDE and say why; carry the losing image as a named alternative. Provenance on every
                        paragraph: (flywheel) (founder) (machine) (ceo) or NEW.
2. THE FOURTEEN, GROWN  one merged section per territory, 6–12 lines, with provenance.
3. SLICE OR SMALL       one row per territory: the year-one frame vs the picture. SLICE = same shape, smaller,
                        grows into the picture through its own reopen triggers. SMALL = a different shape that
                        would have to be torn out. For every SMALL row: what the frame should say instead,
                        concretely, and what it costs to change now versus later.
4. THE PATH BACKWARDS   month one derived FROM the picture, ≤ 14 steps. Beside each step: does the frame's §15
                        already have it (same / moved / missing)?
5. WHAT COMPOUNDS       the flywheels, merged, each with store · feeder · reader · what it changes.
6. WHAT WOULD HAVE TO BE TRUE  ranked; mark which are measurable this month.
7. THE FOUNDER'S CHOICES  every place the picture asks the founder to decide something the frame decided
                        differently, as a table: topic · frame says · picture says · what changes if the
                        founder picks the picture.
```
Rules: no averaging of visions; a decision is one image, not a blend. Do not soften the picture to fit the
frame — §3 exists precisely so the two can disagree in writing. Every "NEW" mechanism is justified in one line.
