# Framing — the night

It is 3:14am in 2028. Nobody is awake. Describe what is running, on what, with which hands, and why it is safe.
Start from the process list and each process's argv, then go up: what is being made right now, in how many
variants, for which ventures; what is being learned and written where; what is being judged and by what; what
is being published, sent, spent, and how each of those got its permission; what the machine does when it is
stuck, bored, or done; what it does when the founder's laptop is shut. Then the morning: what is waiting. The
question you are answering: **how big can the unattended machine be, and what makes each additional hand safe
by construction rather than by rule?**
