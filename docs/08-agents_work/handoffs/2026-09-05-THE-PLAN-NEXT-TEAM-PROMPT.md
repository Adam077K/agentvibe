## What on disk already answers part of this, measured 2026-09-04 (CENSUS.md)

- **Mission control exists in code** on this branch: `mission-control/` — 60 files, a Bun + Hono server with an SSE
  feed, a React `client/`, `scripts/consume-dispatch.ts` (685 lines, the founder-run queue consumer), and
  `~/.agentvibe/events.jsonl` (1.1 MB, 3,840 rows) as its typed event log. The final plan marked it ABSORBED; the
  founder wants it back as a first-class surface. `war-room/` (62 files, a tmux dashboard) and `bin/warroom` (3,429
  lines: per-worker cost pricing, typed events, snapshots) are the other substrates.
- **Terminals on the Mac already have handles**: Claude Code ships `-w <worktree>` and `--tmux`, `claude agents` (a
  state-ordered strip board with peek-and-reply), a messaging socket a shell script can inject into between tool
  calls, `--session-id <uuid>` so the system assigns the id, and Remote Control. Gemini CLI ships `-w`. These are the
  primitives "click an agent and its terminal pops up" would sit on.
- **The room survey exists**: `docs/03-system-design/round-5/research/surfaces.md` §4A on branch ceo-1 catalogues
  open-source office and floor renderers with licences read from files; Generative Agents' `demo` mode (Apache 2.0,
  one JSON file, no model) ranked first. The 3D file graph, the kanban-to-session launcher and the agent canvas were
  not surveyed; they are new research.
- **Eighteen agent files exist** (`.claude/agents/`, seven engines and eleven shims), each with `model:`, `tools:`,
  `maxTurns:`, two with `mcpServers:`; `PROMPT-STANDARD.md` and the `PS-*` lint govern them. A ten-to-fifteen agent
  roster has a file format, a lint and a grant mechanism to start from; the final plan §7.5 has the measured argv
  that narrows a child, and §9.7 the managed-settings seam that holds it.
- **The skills**: 134 in `.claude/skills/`, classified by fate in CENSUS.md §3 (73 procedure · 22 anchor candidates
  · 16 exemplar candidates · 1 rehearsal case · 22 vendor guides); `CURATION.yml` records every cut with its test;
  the catalogue of 177 open-source projects is `docs/02-competitive/expansion/open-source.md` on ceo-1.
- **Providers on this Mac**: Claude Code 2.1.259 measured; `gemini` 0.38.2 installed and never authenticated;
  `codex` not installed, and openai/codex#19945 (exit 0 with empty stdout when detached from a TTY on a non-trivial
  prompt) open since 2026-04-28. "Codex from day one" therefore begins with installing it and measuring that defect.
- **The connected tools** are listed with class and credential in FINAL-PLAN.md §16.3; `.claude/mcp-policy.json`
  is the per-server allow/deny shape, in shadow mode.
