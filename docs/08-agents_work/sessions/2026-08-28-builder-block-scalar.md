# A block scalar is content, and the parser was reading it as a stream of scanned lines

**The root cause is a whole-document pre-pass, not a line-level bug.** `scanLines()` normalises every line of the document before any structure is known: it drops blank lines, drops `#`-first lines, runs `stripComment` on every line, right-trims, and strips all leading indentation. All five are correct for a plain scalar and all five destroy a block-scalar body, which the `>`/`|` branch then reassembled from that already-normalised stream. **Two of the five delete the line from `lines[]` entirely**, so the body was not reconstructible from the scan's own output — which is why the fix reads back into the raw source and every scanned line now carries its raw index. Five content losses fixed: a `#` preceded by whitespace truncated the value; a `#`-first line vanished; a blank line vanished, and in `>` that destroys the fold boundary so `alpha\nbravo` became `alpha bravo`, a different sentence; relative indentation flattened to column 0; trailing whitespace was stripped.

**Differential result, with its denominators.** 32 probe cases against **PyYAML 6.0.3** and **js-yaml 4.1.1**, the two reference arms agreeing on **all 32** — so no case is ambiguous and no verdict rests on one implementation's quirk. Before: 11 AGREE. After: **18 AGREE · 11 DIFFER · 3 OURS-THROWS · 0 SUBSTANTIVE.** Every one of the 11 diffs is the deliberate trailing `\n`; all 3 throws are the deliberate `|+`/`>+`/`|2` refusal. Live corpus of 44 documents that real consumers feed the parser: **1 SUBSTANTIVE before → 0 after**, and `.claude/gates.yml` stayed at exactly **15** trailing-newline-only, which is the control that says nothing there was broken. *An instrument note worth keeping: the first corpus run reported 76 SUBSTANTIVE findings and 75 of them were js-yaml resolving ISO dates to `Date` while the other two arms return strings. **Chomping stays `strip`, and it is a decision now rather than an accident.** YAML's default is `clip`; this parser applies `strip` to all four indicators it accepts. Kept for three measured reasons: `|-` and `>-` already match both references byte for byte, so adopting clip would make `|` and `|-` **diverge where they agree today**; every value it would change sits on an `irreversible`-tier surface and the change recovers **zero** content; and the trailing newline is the only remaining gap from a conforming parser, so stating it states the whole gap. `|+`, `>+` and `|2` still throw `unexpected indentation` — refuse rather than guess. A test names the decision and its reason, so deleting it deletes the reasoning too.
