**Three hooks match command text instead of parsing it, and all three fired this session.**
- `git checkout --`: the predicate `git\b.*checkout\b.*--\s+` is evaluated against the **whole
  multi-line command flattened to one line**. Proved directly: `git`+`checkout` on line 1 and `-- ` on
  line 3, nothing matching on any single line, still blocked. Any multi-line script containing a
  `checkout` token anywhere and a `-- ` anywhere is refused, at any distance.
- `npx`: `(^|[;&|]\s*)(npx|bunx)\b` blocks the word appearing in a **string being written**, not only a
  command being run. A lane had to rephrase a prompt's contents to get past it.

  `sandbox.filesystem.allowWrite` explicitly grants `/private/tmp/claude-501`. Two controls disagree
  about the same path. Every lane worked in the scratchpad via Bash because the Write tool would not.
  This is not an argument that the agents did wrong — it is that one of the two controls is not

## Corrections — four of them the orchestrator's own

1. **`fix/audit-repairs` was reported as `lite`. It is `irreversible`.** The file list was passed
   unquoted in zsh, which does not word-split, so `classify.mjs` received one argument and answered for
   the wrong path — trap #4 of the previous handoff, walked into immediately after reading it. Caught
   only because a branch touching `.claude/hooks/` cannot be `lite`. Via `xargs` it is `irreversible`
   through `.claude/hooks/pre-tool-use.sh`. **Its session files declare `tier: full`** — the gate accepts
   `full|irreversible`, so it passes, but the declared tier understates the floor.
2. **`npm run check` was reported as exiting 0.** That was `tail`'s exit status; the command had been
   piped. The real exit was 1. The shape of this error — a measurement that could not support the
   conclusion drawn from it — is the one this repo names as its central failure mode, and it was
   committed while holding the paragraph that names it.
3. **"`npm run check` aborts at step 8" was stated as general. It is specific to the session's own
   worktree.** A lane reported the abort at step 1 in its clone and flagged the difference honestly
   rather than asserting the measurement was wrong; a second lane independently found the cause. Both
   readings are correct in their own environment.
4. **"Zero agents dispatched" was an unachievable requirement**, written into a brief before checking.
   Workflow scripts get no filesystem or `child_process` access, so `npm run check` can only run inside
   an agent holding Bash. The achievable property is **zero *panel* agents on a red oracle**, which is
   what was built and demonstrated. The brief asked for something the runtime forbids.
