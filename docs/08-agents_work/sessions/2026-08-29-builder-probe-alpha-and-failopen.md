# A translucent colour was measured as opaque, and four predicates failed open

**The p1 is a SILENT PASS on a real WCAG failure, and every figure below is a run.** `parseRgb('rgba(0, 0, 0, 0.03)')` returns `[0,0,0]` — opaque black — so `#eee` on a 3% black scrim measured **18.100:1** where the composited truth is **1.083:1** against a 4.5 floor, and the probe emitted **zero findings**. The foreground direction is the same: `color: rgba(0, 0, 0, 0.05)` over white read as **21:1**, the maximum possible ratio, on text that is nearly invisible. A 3% scrim is ordinary CSS.

**It is a p1 rather than a documented limitation because of what it did with the unmeasured pair.** `design-lib.mjs` records alpha-dropping as deliberate and ends *"callers that need it must composite first. Neither instrument does today."* This is that caller, and it did neither — it did not composite and it did not decline. The result was nothing in `gaps`, nothing in `unchecked`, nothing anywhere in the artifact, which is this file's own invariant broken on the axis its other two p1s are about.

**Refusal, not compositing, and the reason is bounded rather than a preference.** `pairColors()` refuses any pair whose foreground or backdrop has alpha ≠ 1, so the pair is NOT CHECKED, is counted, and reaches the verdict as INCOMPLETE. Compositing needs *every* layer beneath the pair and `collect()` returns ONE backdrop — the first ancestor that is not fully transparent — so a composited number here would be a plausible wrong answer standing where there is now an honest hole. That is the defect `canvasBackground()` was written to end, one axis over. Compositing remains the better fix and is a change to what the instrument measures, which is a decision for whoever owns the probe.

**`alphaOf()` reads the COMPONENT COUNT, not the function name, and that distinction is the whole of it.** CSS Color 4 permits `rgb(0, 0, 0, 0.03)`, Chromium emits it, and `parseRgb` accepts that form and drops the alpha — so a check keyed on `rgba(` would have missed exactly the dangerous case. Unreadable alpha (`var(--a)`) fails closed.

**The backdrop walk no longer stops on a string.** It tested `bg === 'rgba(0, 0, 0, 0)'`, the exact sentinel, so `rgba(255, 255, 255, 0)` halted it and was measured as opaque white paint that nothing paints. Alpha is the property; the spelling was never the rule. The walk now passes any fully transparent ancestor and stops at the first that paints.
