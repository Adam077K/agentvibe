# The probe stopped holding an opinion about type and started asking the token file
**Deleted a rule this repo invented and the research falsified, and recorded the deletion at both sites.** `MIN_STEP_RATIO = 1.125`, `scaleGaps()` and the `type-scale-near-duplicates` finding are gone. The falsification is not a matter of tuning: a UI band on a constant integer increment has `ratio = 1 + d/s`, which **decreases monotonically** (11→12 is 1.091, 14→15 is 1.071), so a flat ratio floor condemns exactly the construction it was written to reward — and linear.app, stripe.com and vercel.com all violate it. The test that pinned the boundary in both directions is deleted with it, because a test that pins a falsified rule makes it *harder* to remove.
**Replaced its job, not its opinion:** `token-conformance` reports every rendered `font-size`, `line-height` and `letter-spacing` absent from `design/tokens/tokens.json`, with its usage count and the nearest token. It cannot be wrong about taste because it has no opinion about taste; the finding cites the token file **by path** and says so in its own `note`.
**A silence is never a pass.** A token group the file does not declare produces **no finding and an `unchecked` entry** naming the absence — the real token file (read from `builder-tokens`) declares `fontSize/lineHeight/letterSpacing` and **no motion at all**, so motion conformance is UNCHECKED against it today and says so on stdout and in the artifact. `--out` writes JSON carrying findings AND `unchecked`; a **REFUSAL is written into it as `exit: 2`**, so a reviewer with no browser and no shell cannot read an empty findings list as a clean run.
**Found by running it, not by reading it: the authored easing is not in one place.** Measured in Chromium, one page, one `getAnimations()` call — a `CSSAnimation` carries it on `getKeyframes()[].easing` while `getTiming().easing` reads `"linear"`; a `CSSTransition` is the **exact opposite**. Reading either alone returns a *plausible wrong answer* for half of all motion. The interpretation moved out of `collect()` (serialised into the browser, untestable) into `resolveMotion()`/`authoredEasings()` in node, and the raw capture is pinned as a fixture.
**Verified by breaking it, 19 mutants, one at a time:** delete any single check and a named test goes red — **19 of 19 killed**. One survived the first round (the per-keyframe arm for script-driven `Animation`s), which was a genuinely unguarded line; it has a control now and the round was re-run clean.

The drift guard **refused an earlier exclusion reason** that said "on every CI run" about the test file, reading it as a coverage claim for `design-probe` itself; the claim was made precise and the guard was not touched.
